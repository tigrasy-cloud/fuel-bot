# ⛽ Fuel Availability Bot

Телеграм-бот «где есть бензин»: пользователь выбирает город (или отправляет геолокацию) —
бот показывает АЗС со статусами 🟢 есть / 🟠 очередь / 🟡 мало / 🔴 нет, ценами,
фильтрами по марке топлива и кнопкой маршрута.

## Источник данных

Бот использует те же публичные JSON-эндпоинты, что и сайт [gdebenz.ru](https://gdebenz.ru)
(народная карта: статусы ставят сами водители, 23 000+ АЗС, 571 город):

| Эндпоинт | Что делает |
|---|---|
| `GET /api/cities?q=...` | поиск города по названию |
| `GET /api/stations?lat1&lon1&lat2&lon2` | АЗС в прямоугольнике вокруг города |
| `GET /api/nearby?lat&lon&radius_km&full=1` | ближайшие АЗС к геолокации |

Обязателен заголовок `Referer: https://gdebenz.ru/` — уже встроен в клиент.

Про 2ГИС и Яндекс Карты: у них нет открытых данных о *наличии* топлива — только
каталог заправок, а gdebenz уже покрывает 23k+ АЗС. Прямой парсинг Яндекс.Карт
нарушает их условия использования. Поэтому в боте ссылки «Маршрут» (Яндекс) и
«2ГИС» встроены прямо в карточку АЗС — так пользователь получает и каталог, и
навигацию, а бот остаётся легальным. Если появится API-ключ 2ГИС — каталог можно
подключить как второй источник: архитектура `sources/` это позволяет.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) → получи токен.
2. Скопируй `.env.example` в `.env` и вставь токен:
   ```
   BOT_TOKEN=123456:ABC...
   ```
3. Запусти `start_bot.bat` (двойной клик) — он сам поставит зависимости
   и поднимет бота. Либо вручную в терминале (не внутри Python!):
   ```bash
   pip install -r fuel_bot/requirements.txt
   python -m fuel_bot.main
   ```

### Если api.telegram.org заблокирован провайдером

Проверка: `curl -m 10 https://api.telegram.org/` — если таймаут, у тебя
три бесплатных варианта (без постоянного VPN):

1. **Cloudflare Worker (рекомендуется)** — свой бесплатный прокси к Bot API,
   10 минут настройки, работает 24/7. Пошаговая инструкция и готовый
   `worker.js` — в [cloudflare_worker/README.md](cloudflare_worker/README.md).
   Адрес воркера вписываешь в `.env` как `API_BASE_URL=...`.
2. **Раздача с телефона** — часто мобильный оператор не блокирует
   api.telegram.org. Включи на телефоне точку доступа, подключи ПК к ней
   и запусти бота. Подходит для быстрой проверки.
3. **Свой socks5/http-прокси** — впиши в `.env`:
   `PROXY_URL=socks5://host:port`.

MTProto-прокси (как в приложениях для разблокировки Telegram Desktop)
боту не подходят: Bot API работает по HTTPS, а не по MTProto.

## Как пользоваться

- `/start` — приветствие и кнопки.
- Напиши город («Казань») → выбери из списка → получишь сводку и список АЗС.
- Или нажми «📍 АЗС рядом со мной» и отправь геолокацию.
- Фильтры: статус (Все / 🟢 / 🟠 / 🔴) и марка (АИ-92 / 95 / 98 / ДТ).
- «🔄 Обновить» — перезапрос с источника (между обновлениями кэш 90 секунд,
  чтобы не дёргать сайт).
- «✍️ Отметить статус» — пользователь сам ставит статус АЗС
  (🟢 есть / 🟠 очередь / 🟡 мало / 🔴 нет). Отметки хранятся в своей БД,
  действуют 6 часов, переопределяют статус источника в списке
  (пометка «✍️ от водителей бота ×N») и видны всем пользователям бота.
- «💰 Следить за ценой» — подписка на минимальную цену марки топлива
  в городе/точке: при изменении на 1₽ и больше приходит уведомление
  со старой и новой ценой и топ-3 самых дешёвых АЗС.
- «🗺 Открыть карту» — Mini App с интерактивной картой (Leaflet + OSM):
  цветные маркеры по статусам, попап с ценами и кнопкой маршрута.
  Кнопка появляется, если задан `WEBAPP_URL` (нужен публичный HTTPS,
  например ngrok: `ngrok http 8080` → `WEBAPP_URL=https://xxxx.ngrok.io/map`).

## Подписки и уведомления

- Кнопка «🔔 Уведомить, когда появится топливо» в списке АЗС подписывает
  на текущий город/геоточку. Бот предложит выбрать марку топлива
  (любое / АИ-92 / АИ-95 / АИ-98 / ДТ) — уведомления придут только про неё.
  При подписке текущий набор 🟢-АЗС запоминается как базовый — спама
  о том, что и так есть, не будет.
- Фоновая задача (`notifier.py`) раз в `CHECK_INTERVAL_SEC` секунд
  (по умолчанию 300 = 5 минут) перепроверяет все подписки и шлёт сообщение,
  только если появились **новые** 🟢-заправки (до 5 штук в сообщении + «и ещё N»).
- Подписки хранятся в SQLite (`fuel_bot/bot.db`) и переживают перезапуск бота.
- `/subscriptions` — список подписок с кнопками отписки.
- Лимит: 5 подписок на чат. Если пользователь заблокировал бота —
  подписка удаляется автоматически.

## Структура

```
fuel_bot/
├── main.py              # запуск: polling + фоновая задача + веб-сервер карты
├── handlers.py          # команды, город, фильтры, подписки, отметки, цены
├── keyboards.py         # инлайн/реплай клавиатуры, пагинация
├── render.py            # тексты сообщений
├── service.py           # кэш, фильтрация, наложение отметок пользователей
├── models.py            # Station, City, статусы
├── storage.py           # SQLite: подписки, отметки, подписки на цены
├── notifier.py          # фоновые проверки: новые 🟢 и изменение цен
├── webapp.py            # aiohttp-сервер Mini App (карта + прокси API)
├── webapp_static/
│   └── map.html         # Leaflet-карта АЗС
└── sources/
    ├── gdebenz.py       # асинхронный клиент API gdebenz.ru
    ├── yandex_maps.py   # категория «АЗС с топливом» Яндекс.Карт (парсинг поиска)
    └── russiabase.py    # russiabase.ru: цены и наличие топлива (справочники + SSR-страницы)
```

## Источники данных

- **gdebenz.ru** — основа: 23k+ АЗС, народные статусы наличия.
- **Яндекс.Карты** — категория «АЗС с топливом»: совпавшие станции получают
  бейдж «✅ Яндекс подтверждает», новые добавляются в список.
- **russiabase.ru** (АЗС-Локатор) — цены по всем маркам (АИ-92…100, ДТ, газ)
  и статусы наличия из поля restrictions; совпавшие станции дополняются
  ценами (бейдж «✅ RussiaBase подтверждает»), новые добавляются.
  Справочники городов/брендов кэшируются в `rb_dicts.json` на 30 дней.

Переменные окружения: `BOT_TOKEN` (обязательно), `CHECK_INTERVAL_SEC`
(интервал проверки подписок, по умолчанию 300), `MAP_HOST`/`MAP_PORT`
(веб-сервер карты, по умолчанию 127.0.0.1:8080), `WEBAPP_URL`
(публичный HTTPS-адрес карты — включает кнопку «🗺 Открыть карту»).

## Идеи для развития

- АЗС вдоль маршрута (точка А → точка Б).
- Отправка отметок пользователей в gdebenz (сейчас — только своя база внутри бота).
- Второй источник (2ГИС Catalog API с ключом) как fallback-каталог.
- FSM → Redis, чтобы состояние переживало перезапуск.
- Docker + webhook-режим для продакшн-деплоя.
